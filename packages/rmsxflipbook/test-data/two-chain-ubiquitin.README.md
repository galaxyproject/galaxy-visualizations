# Fresh Galaxy output fixture

Generated September 8, 2026 by a real Galaxy job using the multi-chain wrapper
0.1.0+galaxy1 candidate, source tag v0.2.3/runtime package 0.1.0, and the published
0.2.3-galaxy0 container (digest 692cbf350ad6ef71e582375d16789d775f5af70ecec18c5e63b002a4d60e1d40).

The input is the 36-frame two-chain regression derivative in the wrapper repository.
Both chains derive from the TCBG ubiquitin trajectory, with B translated 45 Angstrom
along X. This is not an independent biological two-chain simulation. Source
attribution and educational-use redistribution terms: https://www.ks.uiuc.edu/Training/CaseStudies/
and https://www.ks.uiuc.edu/copyright.html. Preserve attribution when redistributing.

Nine slices contain four frames each, with actual source timestamps and frame
bounds. The test checks the manifest from computation through Analysis rendering.
