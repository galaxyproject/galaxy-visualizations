# RNA-seq analysis report

This report summarises a **differential expression** run on *Galaxy*. See [the Galaxy Training Network](https://training.galaxyproject.org) for the tutorial, or visit https://usegalaxy.org.

## Steps

1. Quality control with `FastQC`
2. Mapping with `HISAT2`
3. Counting with `featureCounts`

- Inputs are paired-end reads
- Reference genome: hg38
